Part H: Reflection
Before using AI, I built a prototype appointment program for SmartCare using python variables and print statements. I then enhanced it by using a list, dictionary and functions to be able to store and display appointment information.

AI helped me to better understand the use of functions, lists and dictionaries and how they can work in tandem with each other. It also explained the limittions of my code and suggested improvements to my code. One suggestion was validating user inputs to ensure patient name, practitioner name and appointment time were not blank or in the wrong format. 

The AI had made assumptions when generating it's code. It assumed that appointments only needed to be stored in memory and that no error handling or validation was needed. As a result, the program accepted blank/unusual inputs and double bookings.

I tested the AI code by testing a normal appointment, a blank patient name, and two appointments for the same practitioner and time. The code allowed these bookings to be displayed without any errors regardless of the inputs. 

The engineering work remained for me as I analysed and compared the results of both human and AI code, identified limitations and implemented improvements by adding a validation function to ensure a patients name cannot be left blank when creating appointments.
